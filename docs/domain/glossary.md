# Glossário — termos da ficha × termos do livro

A UI usa os termos da **ficha oficial** (imagem de referência); o livro desta tradução
às vezes usa outro nome. Mostramos ambos via `glossary-term`.

| Termo na ficha (UI) | Termo no livro | Significado para iniciante |
|---|---|---|
| Força, Destreza, Constituição, Inteligência, Sabedoria, Carisma | idem ("valores de habilidade") | Os 6 atributos; valor 1–20 (máx. 30) |
| Modificador | Modificador de habilidade | Número somado às rolagens, derivado do atributo |
| Bônus de Proficiência | idem | Bônus que cresce com o nível; somado ao que você é treinado |
| Salvaguardas | Testes de Resistência | Rolagem para resistir a um efeito (veneno, magia…) |
| Perícias | Perícias | Treinos específicos ligados a um atributo |
| Lidar com Animais | Adestrar Animais | Perícia de Sabedoria |
| Sabedoria Passiva (Percepção) | Percepção passiva | Quanto você nota sem rolar dado |
| Classe de Armadura (CA) | idem | Dificuldade para ser atingido |
| Dado de Vida | idem | Dado usado para PV por nível e descanso |
| Deslocamento | idem | Metros por turno |
| Especialização | Especialização | Dobra o bônus de proficiência numa perícia (Ladino, Bardo) |
| Versatilidade | Versatilidade (Bardo) | Soma metade da proficiência em perícias sem treino |
| Traço racial | Traço | Habilidade que vem da raça |
| Característica de classe | Característica | Habilidade que vem da classe, liberada por nível |
| Antecedente | Antecedente | História do personagem; dá 2 perícias |

## As 18 perícias e seu atributo
| Atributo | Perícias |
|---|---|
| Força | Atletismo |
| Destreza | Acrobacia, Furtividade, Prestidigitação |
| Inteligência | Arcanismo, História, Investigação, Natureza, Religião |
| Sabedoria | Intuição, Lidar com Animais, Medicina, Percepção, Sobrevivência |
| Carisma | Atuação, Enganação, Intimidação, Persuasão |
| Constituição | — (nenhuma perícia) |
