## Escopo do MVP (a partir dos critérios de pronto)
1. Raça/sub-raça → traços e bônus.
2. Classe + nível → características até o nível.
3. Perícias e salvaguardas → valor e **como calcular**.
4. Todos os bônus → **origem e tipo**.

Fora do MVP: magias detalhadas, equipamento, multiclasse, talentos, arquétipos detalhados.
